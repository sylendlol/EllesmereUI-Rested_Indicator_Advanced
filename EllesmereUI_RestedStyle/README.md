# EllesmereUI Rested Style

Standalone add-on for WoW Forever (Interface 16001), EllesmereUI 9.6. No EllesmereUI file is modified.

Replaces the "ZZZ" text of EllesmereUI's Rested Indicator with a selectable style:

- Blizzard (animated): Blizzard's own rest flipbook, read from the client's PlayerFrame (static UI-StateIcon if the client has no such atlas). Size, tint, animate on/off, speed, desaturate.
- Classic Badge: round badge with "Zz". Size, text, text size, font, text color, background, ring (accent or own color, thickness), pulse.
- Floating Letters: rising, fading Z letters. Letter count, size, case, font, outline, color (accent / class / gold / custom), cycle time, rise height, drift, opacity.
- Icon Square: buff-icon style square. Size, text, text size, font, colors, border (accent or own color, thickness), pulse and pulse amount.
- EllesmereUI (ZZZ text): the original look.

Settings: EllesmereUI > Quality of Life > QoL > Rested Indicator > cog (Style, Preview, Anchor, Anchor To, X/Y Offset, then the selected style's settings).

/eurest - toggle preview (shows the indicator outside a resting area)
/eurest reset - reset all Rested Style settings

Saved variables: EllesmereUI_RestedStyleDB.
